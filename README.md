# AML Transaction Monitoring & Investigation Platform

An end-to-end AML Transaction Monitoring simulation built using **PostgreSQL, SQL and Tableau**.

The project models how financial institutions identify suspicious transactions, generate alerts, manage investigations and monitor operational performance through interactive dashboards.
